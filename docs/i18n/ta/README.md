கட்டமைக்கக்கூடிய எச்சரிக்கை மற்றும் முக்கியமான வரம்புகளுடன் Bitcoin விலையைக் கண்காணிப்பதற்கான ஒரு Nagios/Icinga செருகுநிரல்.

## அம்சங்கள்

- பல நாணயங்களில் (USD, EUR, GBP போன்றவை) Bitcoin விலையைக் கண்காணித்தல்
- கட்டமைக்கக்கூடிய எச்சரிக்கை மற்றும் முக்கியமான வரம்புகள் (உயர்ந்த மற்றும் குறைந்த)
- செயல்திறன் தரவுடன் கூடிய நிலையான Nagios செருகுநிரல் வெளியீடு
- CoinGecko API ஐப் பயன்படுத்துகிறது (இலவசம், API விசை தேவையில்லை)
- தனிப்பயன் API முனைப்புள்ளிகளுக்கான ஆதரவு
- கட்டமைக்கக்கூடிய காலாவதி நேரம்
- ஒரு மணி நேர இயல்புநிலை வரம்புடன், விற்பனையாளர் நேரமுத்திரைகளைப் பயன்படுத்தி விலைப்புள்ளி புதுமைச் சரிபார்ப்புகள்
- விகித வரம்புகள் மற்றும் தற்காலிக API தோல்விகளுக்கான வரையறுக்கப்பட்ட மறுமுயற்சிகள்
- அனைத்து முயற்சிகளுக்கும் ஒரே காலக்கெடு மற்றும் ஒவ்வொரு பதிலுக்கும் 64 KiB உச்ச வரம்பு
- 24 மணி நேர முழுமையான சதவீத நகர்வு குறித்த விருப்ப எச்சரிக்கைகள்
- செயல்திறன் தரவில் விலை வரம்புகள், கோரிக்கை கால அளவு மற்றும் விலைப்புள்ளி வயது

## பயன்பாடு

### அடிப்படைப் பயன்பாடு

```bash
# Check Bitcoin price (valid quotes return OK when no thresholds are set)
check_bitcoin_price

# Output: OK - Bitcoin price is 43521.00 USD | bitcoin_price=43521.00;;;0; request_time=0.125s;;;0;
```

### வரம்புகளுடன்

```bash
# Alert if price drops below 30000 or rises above 50000 (warning)
# Alert if price drops below 25000 or rises above 60000 (critical)
check_bitcoin_price -w 30000:50000 -c 25000:60000
```

### தனிப்பட்ட வரம்புகள்

```bash
# Only alert on price drops
check_bitcoin_price --warning-low 30000 --critical-low 25000

# Only alert on price spikes
check_bitcoin_price --warning-high 50000 --critical-high 60000
```

### வெவ்வேறு நாணயம்

```bash
# Check price in EUR
check_bitcoin_price --currency eur

# Check price in GBP
check_bitcoin_price --currency gbp
```

### தனிப்பயன் காலாவதி நேரம்

```bash
# Set a total 30-second budget for requests and retries
check_bitcoin_price --timeout 30
```

### புதுமை மற்றும் மறுமுயற்சி வரம்பு

```bash
# Require a quote no older than five minutes; allow two retries within ten seconds
check_bitcoin_price --max-age 300 --timeout 10 --retries 2
```

விற்பனையாளர் நேரமுத்திரையைக் கொண்ட ஒரு விலைப்புள்ளி இயல்பாக அதிகபட்சம் ஒரு மணி நேரம் பழமையானதாக மட்டுமே இருக்க வேண்டும். `--max-age` இல்லாதபோது விலையை மட்டும் வழங்கும் முனைப்புள்ளிகள் பயன்படுத்தக்கூடியதாக இருக்கும். `--max-age` உடன், விடுபட்ட, தவறான, எதிர்கால அல்லது பழைய விற்பனையாளர் நேரமுத்திரைகள் `UNKNOWN` ஐத் திருப்பி அனுப்பும்; விற்பனையாளரின் விலைப்புள்ளி நேரத்திற்குப் பதிலாக உள்ளூர் பெறுதல் நேரத்தைச் செருகுநிரல் பயன்படுத்தாது. வயது வரம்பில் சரியாக உள்ள நேரமுத்திரை ஏற்றுக்கொள்ளப்படும். எதிர்கால நேரமுத்திரைகள் எப்போதும் நிராகரிக்கப்படும்.

இயல்புநிலை ஒரு மறுமுயற்சியை அனுமதிக்கிறது. இணைப்புப் பிழைகள், காலாவதிகள் மற்றும் HTTP 408/429/500/502/503/504 பதில்கள் மட்டுமே மறுமுயற்சி செய்யப்படுகின்றன. காத்திருப்பு இடைவெளி 0.5 வினாடிகளில் தொடங்கி அடுத்தடுத்த மறுமுயற்சிகளுக்கு இரட்டிப்பாகிறது; `Retry-After` வினாடிகள் மற்றும் HTTP தேதிகள் முன்னுரிமை பெறுகின்றன. அனைத்து முயற்சிகள், பதில் வாசிப்புகள், JSON குறிவிலக்கம் மற்றும் மறுமுயற்சி காத்திருப்புகள் ஆகியவை `--timeout` வரம்பைப் பகிர்ந்து கொள்கின்றன. காலவரம்பிற்குள் பொருந்தாத மறுமுயற்சி காத்திருப்பு உடனடியாக `UNKNOWN` ஐத் திருப்பி அனுப்பி, காலாவதி என்று கூறாமல் அதற்குக் காரணமான `HTTP 429` அல்லது `ConnectionError` போன்ற தோல்வியைப் புகாரளிக்கும். அங்கீகாரத் தோல்விகள், பிற நிரந்தர HTTP பிழைகள், தவறான JSON மற்றும் 64 KiB குறிவிலக்கப்பட்ட தரவை விடப் பெரிய பதில்கள் மறுமுயற்சி செய்யப்படாது. மறுமுயற்சிகளை முடக்க `--retries 0` ஐப் பயன்படுத்தவும்.

### மாற்று விலைப்புள்ளி மூலங்கள்

CoinGecko-இணக்கமான முனைப்புள்ளிகளுடன் மீண்டும் பயன்படுத்தக்கூடிய `--fallback-url URL` விருப்பங்களைப் பயன்படுத்தவும். எடுத்துக்காட்டாக, `--fallback-url https://quotes.example.org/simple/price` ஐச் சேர்க்கவும். ஒவ்வொரு மூலமும் அதன் மறுமுயற்சிகள் உட்பட மீதமுள்ள கோரிக்கை காலக்கெடுவில் சம பங்கைப் பெறுகிறது. தற்காலிகத் தோல்வி அல்லது அந்தப் பங்கை விட நீண்ட மறுமுயற்சி தாமதம் ஏற்பட்டால் அடுத்த மூலத்திற்குச் செல்லும். TLS சரிபார்ப்புத் தோல்விகள், நிரந்தர HTTP பிழைகள் மற்றும் தவறான விலைப்புள்ளிகள் UNKNOWN ஐத் திருப்பி அனுப்பும். ஒவ்வொரு விலைப்புள்ளி பதிலும் 64 KiB குறிவிலக்கப்பட்ட தரவுக்கு வரையறுக்கப்பட்டுள்ளது. மாற்று மூலங்கள் கட்டமைக்கப்படும்போது, நிலை வெளியீடு பதிலளித்த மூலத்தை அதன் URL ஐ அச்சிடாமல் `primary`, `fallback1` எனத் தொடர்ச்சியாக அடையாளம் காட்டும்.

உள்ளூர் Linux அல்லது macOS கோப்பு முறைமையில் கண்காணிப்புப் பயனருக்குத் தனிப்பட்ட எழுதக்கூடிய நிலை அடைவை வழங்கவும். சரிபார்ப்புகளுக்கு இடையில் உடன்பிறப்பு `.lock` கோப்பை அப்படியே வைத்திருக்கவும். ஒவ்வொரு கால அளவிற்கும் தனித்தனி நிலைக் கோப்பைப் பயன்படுத்தவும். நாணயங்கள் அதற்குள் சுயாதீனமான வரலாறுகளைக் கொண்டுள்ளன. இயல்புநிலை கால அளவு 3600 வினாடிகள். ஒவ்வொரு செல்லுபடியாகும் விலைப்புள்ளிக்கும் கால அளவு மற்றும் வயது வரம்பிற்குள் விற்பனையாளர் நேரமுத்திரை தேவை, `--max-age` வேறு ஒன்றை அமைக்காவிட்டால் இது ஒரு மணி நேரமாகும். செருகுநிரல் தற்போதைய விலையை அந்தக் கால அளவில் உள்ள பழமையான முந்தைய நேர்மறை விலையுடன் ஒப்பிட்டு, உண்மையான கடந்த வினாடிகளைப் புகாரளிக்கிறது. மீண்டும் வரும் நேரமுத்திரைகள் கூடுதல் மாதிரிகளை உருவாக்காது. முதல் மாதிரி, காலாவதியான வரலாறு அல்லது சிதைந்த JSON ஆகியவை புதிய அடிப்படை மதிப்பைத் தொடங்குகின்றன; ஒப்பிடக்கூடிய மாதிரி கிடைக்கும் வரை கால அளவு அளவீடு அறியப்படாததாக இருக்கும். பிற எச்சரிக்கைகள் தொடர்ந்து பொருந்தும். எழுத முடியாத நிலை, குறியீட்டு இணைப்பு நிலை அல்லது பூட்டுக் கோப்பு, அல்லது புதியதாகப் பதிவு செய்யப்பட்ட மாதிரியை விடப் பழமையான விலைப்புள்ளி ஆகியவை UNKNOWN ஐத் திருப்பி அனுப்பும். குறியிடப்பட்ட `bitcoin_move_window` அளவீடு சமச்சீர் எச்சரிக்கை மற்றும் முக்கியமான வரம்புகளைப் பயன்படுத்துகிறது. வரம்பில் சமமாக இருப்பது எச்சரிக்கையை ஏற்படுத்தாது.

செருகுநிரல் ஒரு சரிபார்ப்புக்கு ஒரு முறை நிலை அடைவைத் திறந்து அதைச் சார்ந்து செயல்படுகிறது, எனவே சரிபார்ப்பின் போது மாற்றப்பட்ட பாதைக் கூறு பூட்டு, வாசிப்பு அல்லது எழுதுதலைத் திசைதிருப்ப முடியாது. சரிபார்ப்பு தொடங்கும்போது பாதையின் அடைவுப் பகுதியில் உள்ள குறியீட்டு இணைப்புகள் பின்பற்றப்படுகின்றன, இது macOS இல் உள்ள `/var` போன்ற தள இணைப்புகளைப் பயன்படுத்தக்கூடியதாக வைத்திருக்கிறது. எனவே நிலை அடைவும் அதன் மேல் அடைவுகளும் பிற பயனர்களால் எழுதக்கூடியதாக இருக்கக் கூடாது. நிலை மற்றும் பூட்டுக் கோப்புகள் 0600 பயன்முறையுடன் உருவாக்கப்படுகின்றன.

### தினசரி சதவீத நகர்வு

```bash
# Warn on a daily move greater than 5%; critical above 10%, in either direction
check_bitcoin_price --warning-change 5 --critical-change 10 --max-age 300
```

மாற்ற வரம்புகள் தேர்ந்தெடுக்கப்பட்ட நாணயத்தில் CoinGecko இன் குறியிடப்பட்ட 24 மணி நேர சதவீத மாற்றத்தின் முழுமையான மதிப்பை அளவிடுகின்றன. ஒரு மாற்றம் சரியாக வரம்பில் இருந்தால் எச்சரிக்கை ஏற்படாது. இரண்டு வரம்புகளும் வழங்கப்பட்டால், எச்சரிக்கை வரம்பு முக்கியமான வரம்பை விட அதிகமாக இருக்கக் கூடாது. தேவையான மாற்றத் தரவு விடுபட்டிருந்தால் அல்லது தவறாக இருந்தால் `UNKNOWN` திருப்பி அனுப்பப்படும். விலை மற்றும் மாற்ற எச்சரிக்கைகளை இணைக்கலாம்; மிக உயர்ந்த தீவிரம் வெற்றி பெறும், தீவிரங்கள் பொருந்தும்போது விலைக்கு முன்னுரிமை அளிக்கப்படும்.

## Nagios கட்டமைப்பு

### கட்டளை வரையறை

Nagios வள மேக்ரோ `$USER1$` ஐ செருகுநிரல் அடைவிற்கு அமைக்கவும் (இயல்புநிலைப் பொதிகள் `/usr/lib/nagios/plugins` ஐப் பயன்படுத்துகின்றன). உங்கள் Nagios கட்டளைகள் கட்டமைப்பில் சேர்க்கவும்:

```cfg
define command {
    command_name    check_bitcoin_price
    command_line    $USER1$/check_bitcoin_price -w $ARG1$ -c $ARG2$ --currency $ARG3$
}
```

### சேவை வரையறை

```cfg
define service {
    use                     generic-service
    host_name               localhost
    service_description     Bitcoin Price
    check_command           check_bitcoin_price!30000:50000!25000:60000!usd
    check_interval          15
    retry_interval          5
}
```

```conf
object CheckCommand "bitcoin_price" {
```

## வெளியேற்றக் குறியீடுகள்

தவறான தருமதிப்புகள், நேர்மறையல்லாத காலாவதிகள், தவறான வரம்பு எல்லைகள் மற்றும் தவறான வடிவமைப்புடைய API விலைகள் `UNKNOWN` (வெளியேற்றம் 3) ஐத் திருப்பி அனுப்பும். வரம்புகள் வரையறுக்கப்பட்ட, எதிர்மறையல்லாத எண்களாக இருக்க வேண்டும், மேலும் ஒவ்வொரு குறைந்த எல்லையும் அதன் உயர் எல்லையை விட அதிகமாக இருக்கக் கூடாது. நாணயம் 2-16 எழுத்துகள் அல்லது இலக்கங்களாக இருக்க வேண்டும். API ஐத் தொடர்பு கொள்வதற்கு முன்பே தவறான கட்டமைப்பு நிராகரிக்கப்படும். விலைகள் வரையறுக்கப்பட்டதாகவும் எதிர்மறையல்லாததாகவும், JSON எண்களாகவோ அல்லது `"43521.5"` போன்ற எளிய தசம சரங்களாகவோ வழங்கப்பட வேண்டும். கோரப்பட்ட நாணயம் இல்லாத பதில், எடுத்துக்காட்டாக `Response has no EUR price` என அதன் பெயரைக் குறிப்பிடும். தவறான பதில்கள் செயல்திறன் தரவை வெளியிடாது. stdout இல் ஒரே ஒரு கண்காணிப்பு நிலை வரி மட்டும் இருக்கும் வகையில் விரிவான கண்டறிதல் தகவல்கள் stderr க்குச் செல்லும்.

| குறியீடு | நிலை | விளக்கம் |
|------|--------|-------------|
| 0 | OK | விலை ஏற்றுக்கொள்ளக்கூடிய வரம்பிற்குள் உள்ளது |
| 1 | WARNING | விலை எச்சரிக்கை வரம்பைத் தாண்டியது |
| 2 | CRITICAL | விலை முக்கியமான வரம்பைத் தாண்டியது |
| 3 | UNKNOWN | பிழை ஏற்பட்டது (API தோல்வி, காலாவதி போன்றவை) |

```text
bitcoin_price=43521.00;30000:50000;25000:60000;0; request_time=0.125s;;;0; price_age=20.000s;;;0; bitcoin_change_24h=-6.00%;-5:5;-10:10;;
```

விலைச் செயல்திறன் தரவில் கட்டமைக்கப்பட்ட எச்சரிக்கை/முக்கியமான வரம்புகள் மற்றும் பூஜ்ஜிய குறைந்தபட்சம் ஆகியவை அடங்கும். வரம்புகள் முழுத் தசம குறியீட்டில் அச்சிடப்படுகின்றன, ஒருபோதும் முழுமையாக்கப்படவோ அடுக்கு வடிவத்தில் காட்டப்படவோ மாட்டாது, எனவே `14500000:16250000` போன்ற பெரிய மதிப்புகள் பாகுபடுத்தக்கூடியதாக இருக்கும். கோரிக்கை நேரத்தில் அனைத்து முயற்சிகளும் காத்திருப்பு இடைவெளியும் அடங்கும். விற்பனையாளர் செல்லுபடியாகும் நேரமுத்திரையை வழங்கும்போது மட்டுமே விலைப்புள்ளி வயது வெளியிடப்படும்; தினசரி மாற்றம் கிடைக்கும்போது வெளியிடப்படும். மாற்ற வரம்புகள் பூஜ்ஜியத்தைச் சுற்றி சமச்சீராக இருக்கும். தவறான அல்லது பழைய தரவு விலைச் செயல்திறன் தரவு இல்லாமல் `UNKNOWN` ஐ உருவாக்கும். இந்த அளவீடுகளை PNP4Nagios, Grafana அல்லது InfluxDB போன்ற வரைபடக் கருவிகளுடன் பயன்படுத்தலாம்.

## API

இந்தச் செருகுநிரல் இயல்பாக [CoinGecko API](https://www.coingecko.com/en/api) ஐப் பயன்படுத்துகிறது, இது இலவசம் மற்றும் API விசை தேவையில்லை. விகித வரம்புகள் பொருந்தும்.

தனிப்பயன் முனைப்புள்ளிகள் அதே பதில் வடிவத்தைப் பயன்படுத்த வேண்டும்: விலைக்கு `bitcoin.<currency>`, UNIX நேரமுத்திரை வினாடிகளுக்கு `bitcoin.last_updated_at` மற்றும் குறியிடப்பட்ட தினசரி சதவீத நகர்விற்கு `bitcoin.<currency>_24h_change`. `--max-age` மற்றும் மாற்ற வரம்புகள் இல்லாதபோது விலை மட்டுமே தேவை. இருப்பினும், நேரமுத்திரை இருந்தால் அது சரிபார்க்கப்படும்: அது எதிர்காலத்திலோ அல்லது ஒரு மணி நேரத்திற்கு மேல் பழமையானதாகவோ இருக்கக் கூடாது. குறிவிலக்கப்பட்ட பதில் 64 KiB க்குள் பொருந்த வேண்டும்.

ஆதரிக்கப்படும் நாணயங்களில் அடங்குவன: usd, eur, gbp, jpy, aud, cad, chf, cny மற்றும் பல.

## பாதுகாப்பு

கீழே உள்ள நடவடிக்கைகள் தற்போதைய குறியீட்டில் செயல்படுத்தப்பட்டுள்ளன. தவறாகச் செயல்படும் முனைப்புள்ளி அல்லது உள்ளூர் பயனர் கண்காணிப்புப் புரவலனுக்குச் செய்யக்கூடியவற்றை இவை கட்டுப்படுத்துகின்றன; இவை விலைப்புள்ளியையே நம்பகமானதாக்காது.

- HTTPS சான்றிதழ்கள் `requests` இயல்புநிலைகளுடன் சரிபார்க்கப்படுகின்றன, மேலும் சரிபார்ப்பை முடக்கும் விருப்பம் எதுவும் இல்லை. எளிய `http://` ஐப் பயன்படுத்தும் தனிப்பயன் `--api-url` க்கு அத்தகைய பாதுகாப்பு இல்லை.
- DNS, இணைப்பு, வாசிப்புகள், மறுமுயற்சிகள் மற்றும் காத்திருப்பு இடைவெளி ஆகியவை `--timeout` காலக்கெடுவைப் பகிர்ந்து கொள்கின்றன. மெதுவாகத் தரவை அனுப்பும் சக முனையால் அதை நீட்டிக்க முடியாது.
- ஒவ்வொரு பதிலும் சுருக்க நீக்கத்திற்குப் பிறகு 64 KiB ஆக வரையறுக்கப்பட்டுள்ளது, மேலும் திசைதிருப்பல் உடற்பகுதிகள் படிக்கப்படாமல் நிராகரிக்கப்படுகின்றன.
- தனிப்பயன் `--api-url` இல் நற்சான்றிதழ்கள் இருக்கக்கூடும் என்பதால், கோரிக்கைத் தோல்விகள் HTTP நிலை அல்லது பிழை வகையை மட்டுமே அச்சிடுகின்றன.
- `.deb` மற்றும் `.rpm` மூலம் நிறுவப்பட்ட கட்டளை Python ஐத் தனிமைப்படுத்தப்பட்ட பயன்முறையில் இயக்குகிறது. இது `PYTHONPATH`, பயனர் தள அடைவு மற்றும் பணி அடைவில் உள்ள தொகுதிகளைப் புறக்கணிக்கிறது. `pip` நிறுவல் நிலையான கன்சோல் ஸ்கிரிப்டைப் பயன்படுத்தி, அது நிறுவப்பட்டுள்ள சூழலைப் பின்பற்றுகிறது.
- ஒரு சரிபார்ப்புக்கு ஒரு முறை திறக்கப்பட்ட அடைவைச் சார்ந்து, நிலை அல்லது பூட்டுக் கோப்புப் பெயரில் உள்ள குறியீட்டு இணைப்பைப் பின்தொடராமல் நகர்வு நிலை படிக்கப்பட்டு எழுதப்படுகிறது.
- வெளியீட்டுச் சொத்துகள் `SHA256SUMS` உடன் கூடுதலாக உருவாக்க மூலச்சான்று சான்றளிப்புகளையும் கொண்டுள்ளன; [GitHub Releases இலிருந்து](#from-github-releases) என்பதைப் பார்க்கவும்.

## 1.0.0 இலிருந்து மேம்படுத்துதல்

இந்த மாற்றங்கள் 2.0.0 இல் வெளியிடப்படுகின்றன.

- பெரிய `--max-age` வழங்கப்படாவிட்டால், ஒரு மணி நேரத்திற்கு மேல் பழமையான விற்பனையாளர் நேரமுத்திரையைக் கொண்ட விலைப்புள்ளி `UNKNOWN` ஐத் திருப்பி அனுப்பும். நேரமுத்திரையைத் திருப்பி அனுப்பாத முனைப்புள்ளிகள் பாதிக்கப்படாது.
- `--currency` 2-16 எழுத்துகள் அல்லது இலக்கங்களை மட்டுமே ஏற்றுக்கொள்ளும்.
- இலக்கப் பிரிப்பான்கள் அல்லது சுற்றியுள்ள இடைவெளிகளைக் கொண்ட எண் சரங்கள் நிராகரிக்கப்படுகின்றன.
- காலவரம்பிற்குள் பொருந்தாத மறுமுயற்சி காத்திருப்பு `API request timed out` என்பதற்குப் பதிலாக அடிப்படைத் தோல்வியைப் புகாரளிக்கும்.
- இயல்புநிலைப் பொதிகள் இனி `PYTHONPATH` ஐப் பின்பற்றாது.
- ஒரு மில்லியன் அல்லது அதற்கு மேற்பட்ட வரம்புகள் செயல்திறன் தரவில் அடுக்குக் குறியீட்டிற்குப் பதிலாக எளிய தசமங்களாகத் தோன்றும்.

## உள்ளூர்மயமாக்கல்

CLI உதவி, சரிபார்ப்புப் பிழைகள் மற்றும் செருகுநிரல் நிலை விளக்கங்கள் தொகுக்கப்பட்ட stdlib-ஏற்றப்பட்ட பட்டியல்களைப் பயன்படுத்தி 45 மொழி அமைப்புகளை (`en`, `de`, `es`, `fr`, `it`, `pt-BR`, `nl`, `ru`, `uk`, `ja`, `ko`, `zh-CN`, `zh-TW`, `ar`, `hi`, `pl`, `tr`, `sv`, `vi`, `id`, `af-ZA`, `am-ET`, `ar-EG`, `ar-MA`, `fr-MA`, `fr-SN`, `ha-NG`, `ig-NG`, `mg-MG`, `rw-RW`, `so-SO`, `sw-KE`, `xh-ZA`, `yo-NG`, `zu-ZA`, `bn`, `fa`, `he`, `mr`, `ta`, `te`, `th`, `ur`, `ms`, `fil`) ஆதரிக்கின்றன. மொழித் தீர்மானம் முதலில் `--lang`, பின்னர் `LC_ALL`, `LC_MESSAGES` மற்றும் `LANG` ஆகியவற்றைச் சரிபார்த்து, இறுதியில் `en` க்குத் திரும்புகிறது. Nagios நிலை முன்னொட்டுகள் (`OK`, `WARNING`, `CRITICAL`, `UNKNOWN`) மற்றும் செயல்திறன் தரவு அனைத்து மொழி அமைப்புகளிலும் மாறாமல் இருக்கும்.

```bash
check_bitcoin_price --lang de
LANG=ja_JP.UTF-8 check_bitcoin_price --help
```

## மேம்பாடு

[mise](https://mise.jdx.dev/getting-started.html) ஐ நிறுவி, மேலே உள்ள மேம்பாட்டு அமைப்பை இயக்கவும். `mise.toml` ஆனது Python மற்றும் uv ஐப் பொருத்துகிறது. மேம்பாட்டுக் கருவிகள் `pyproject.toml` இல் அறிவிக்கப்பட்டு, சமர்ப்பிக்கப்பட்ட `uv.lock` இல் தீர்க்கப்படுகின்றன.

```bash
mise run check   # lockfile, formatting, lint, and types
mise run test    # unit tests, installed CLI tests, and >=98% branch-aware coverage
mise run audit   # Bandit and locked runtime dependency audit
mise run build   # wheel, source distribution, and strict metadata validation
mise run package # also build .deb, .rpm, and SHA256SUMS
mise run format
```

அமைத்த பிறகு commit கொக்கிகளை நிறுவவும்:

```bash
mise exec -- uv run --frozen --no-sync --no-build pre-commit install
mise exec -- uv run --frozen --no-sync --no-build pre-commit run --all-files
```

சார்புகளைப் புதுப்பிக்க `mise exec -- uv add --dev <tool>` அல்லது `mise exec -- uv add <dependency>` ஐப் பயன்படுத்தி, `pyproject.toml` மற்றும் `uv.lock` இரண்டையும் commit செய்யவும்.

CI ஆனது Linux இல் Python 3.12 மற்றும் 3.13 ஐயும், macOS இல் Python 3.13 ஐயும் சரிபார்க்கிறது. ஒவ்வொரு PR உம் பொதி சரிபார்ப்பு, சார்புத் தணிக்கை மற்றும் CodeQL ஆகியவற்றையும் இயக்கி, Ubuntu இல் `.deb` ஐயும் Fedora இல் `.rpm` ஐயும் நிறுவுகிறது. உருவாக்கப்பட்ட விநியோகங்கள் CI இயக்கங்களில் `distributions` கலைப்பொருளாகக் கிடைக்கின்றன.

பொதி மற்றும் CLI பதிப்பு `check_bitcoin_price/__init__.py` இலிருந்து வருகிறது. பதிப்பு உயர்வுகள் மற்றும் GitHub வெளியீட்டுச் சொத்துகளின் தானியங்கி வெளியீட்டிற்கு [வெளியீட்டுச் செயல்முறை](../../../CONTRIBUTING.md#releases) ஐப் பார்க்கவும்.
